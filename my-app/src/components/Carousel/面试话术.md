# Carousel 面试话术（可直接说）

## 开场（30 秒）

> 我会把 Carousel 建模成 **一个 `index` 作为唯一状态**，轨道用 `translateX(-index * 100%)` 派生。  
> 导航统一走 `goTo` / `next` / `prev`；自动播放、圆点、键盘都复用同一套 API，避免多处改 index 导致状态分叉。

## 核心实现

**状态与动画**

> 视口 `overflow: hidden`，track 是横向 flex，每张 slide `flex: 0 0 100%`。  
> 切页只改 `index`，CSS transition 做位移。若用户开启 `prefers-reduced-motion`，我会关掉 transition 和 autoplay。

**循环与边界**

> `loop` 时用 `((i % n) + n) % n` 处理负数；非 loop 则 clamp，并 disable 两端按钮。  
> 面试官若问「无限无缝轮播」，会再提克隆首尾 slide 或 snappable scroll，那是下一档复杂度，先保证可维护的基础版。

**自动播放**

> `setInterval` + unmount/`deps` 变化时 `clearInterval`。  
> `onTick` 放 ref，避免 interval effect 因回调 identity 反复重建。  
> 暂停要拆原因：hover、内部 focus、`document.hidden`、reduced-motion——不要用一个 `paused` 布尔硬盖，否则切回 tab 或 mouseleave 时容易状态错乱。

**无障碍**

> 根节点 `role="region"` + `aria-roledescription="carousel"`；非当前 slide `aria-hidden`。  
> 标题变化用 `aria-live="polite"` 播报，不抢焦点。  
> 区域可 `tabIndex={0}`，支持 ← →；圆点用 `tablist`/`tab` 或普通按钮 + 清晰 `aria-label`。

## 追问应答

| 追问 | 怎么答 |
| --- | --- |
| 为什么不用 `scrollLeft`？ | 也可以；`scroll-snap` 对触控更自然。`transform` 版状态更可控、易测。生产可两者结合。 |
| 如何避免快速连点 / 动画中途切页？ | 可加 `isAnimating` 锁，或在 `transitionend` 后再接受下一次；基础版直接改 index 也常见。 |
| 图片很大怎么优化？ | 当前页与相邻页优先加载；其余 `loading="lazy"`；注意 `aria-hidden` 的 slide 内链接要不可聚焦（`inert` / `tabIndex={-1}`）。 |
| 受控 vs 非受控？ | 默认内部 `index`；暴露 `index` + `onIndexChange` 即可受控，和 input 同一套路。 |
| 和 Swiper 差在哪？ | 面试题考的是状态机、副作用清理、a11y；库还处理手势、虚拟 slide、断点、RTL 等。 |

## 收尾加分句

> 我会先交付 **可访问 + 可暂停的基础轮播**，再按需求加触摸手势和无缝无限循环；先把 index 单一数据源和 timer 生命周期讲清楚，比一上来堆特效更稳。
